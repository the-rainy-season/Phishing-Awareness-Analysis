# Phishing Awareness Analysis

## 📌 Project Description

Phishing Awareness Analysis is a cybersecurity project developed using Python to identify potential phishing emails and suspicious messages. The application analyzes message content for phishing indicators such as suspicious keywords, malicious links, URL shorteners, urgency tactics, and requests for sensitive information. It generates a risk score, lists detected red flags, and explains why a message may be unsafe.

---

## 🚀 Features

- Email and message analysis
- Suspicious keyword detection
- URL and link inspection
- Shortened URL detection
- Risk score calculation
- Red flag reporting
- Security recommendations
- Phishing threat identification

## ▶️ How to Run

1. Install Python on your system.
2. Save the source code as:

   phishing_analyzer.py

3. Open Terminal or Command Prompt.
4. Navigate to the project directory.
5. Run:

   python phishing_analyzer.py

6. Paste the email/message to analyze.
7. Type END on a new line (if using multi-line input version).
8. View the phishing analysis report.

## 🔒 Security Recommendation

- Do not click unknown links.
- Verify sender identity before responding.
- Never share passwords, OTPs, or banking credentials.
- Check URLs carefully before visiting websites.
- Report suspicious emails to security teams.
